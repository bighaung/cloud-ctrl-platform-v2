 建立日期：2026-06-11

【專案簡介】
多雲帳號管理平台，統一監控阿里雲與騰訊雲的資源、費用、安全告警。

【技術架構】
  前端：HTML / React JSX（Dashboard + 帳號管理介面）
  後端：Node.js + Express
  資料庫：PostgreSQL（帳號設定、快照、告警、審計日誌）
  快取：Redis（API 快取、Session、STS Token）
  部署：Docker Compose（本地/ECS 通用）

【檔案清單】
  cloud-ctrl-platform-v2/     後端完整代碼（主要）
  cloud-account-manager.html  帳號管理介面（新增/刪除阿里雲+騰訊雲帳號）
  aliyun-dashboard-preview.html  Dashboard 預覽（資源/費用/告警總覽）

【代碼目錄結構】
  cloud-ctrl-platform-v2/
  ├── backend/
  │   ├── src/
  │   │   ├── index.js                 主入口
  │   │   ├── config/
  │   │   │   ├── db.js                PostgreSQL 連線
  │   │   │   ├── redis.js             Redis 連線
  │   │   │   └── logger.js            Winston 日誌
  │   │   ├── middleware/
  │   │   │   └── auth.js              JWT 驗證 + RBAC 角色控制
  │   │   ├── routes/
  │   │   │   ├── auth.js              登入/登出/改密碼
  │   │   │   ├── cloudAccounts.js     統一雲帳號 CRUD（阿里雲+騰訊雲）
  │   │   │   ├── resources.js         資源查詢 API
  │   │   │   ├── alerts.js            告警管理

Q：這需要建在哪裡？
A：建議本地測試先跑，之後搬到 ECS

用戶環境：本地測試 + 已有阿里雲 ECS

本地啟動步驟：

  2. 複製 .env.example 為 .env，填入密碼

Q：我需要先測試一個阿里雲帳號，他需要什麼權限？以及在網頁上哪裡可以輸入？

A：阿里雲測試帳號最小權限：
   - AliyunECSReadOnlyAccess
   - AliyunRDSReadOnlyAccess
   - AliyunOSSReadOnlyAccess
   - AliyunBSSReadOnlyAccess
   - AliyunActionTrailReadOnlyAccess

產出：cloud-account-manager.html（帳號管理介面）
功能：新增/刪除/同步 阿里雲+騰訊雲帳號，含顏色選擇、預算設定

---

Q：騰訊雲帳號一樣可以用管理介面增加刪除嗎？
A：可以，cloud-account-manager.html 已支援，選「🔵 騰訊雲」填 SecretId/Key

---

Q：我有一個阿里雲主帳號，要怎麼設定？

A：完整設定步驟：

Part 1（主帳號，只做一次）：
  1. RAM 控制台建立用戶 cloud-ctrl-service
  2. 賦予自訂策略：sts:AssumeRole
  3. 生成 AccessKey → 填入 .env

Part 2（每個子帳號）：
  1. 子帳號 RAM 建立角色 AliyunCtrlReadOnly
  2. 信任策略填主帳號 UID
  3. 附加 5 個只讀策略
  4. 記錄 Role ARN

Part 3：
  - .env 填主帳號 Key
  - 管理介面填帳號 ID + Role ARN

 重要設定備忘
================================================================

後端 API 端點：
  POST   /api/auth/login               登入
  POST   /api/auth/logout              登出
  GET    /api/auth/me                  取得當前用戶
  GET    /api/cloud-accounts           列出所有帳號
  POST   /api/cloud-accounts           新增帳號
  POST   /api/cloud-accounts/:id/sync  手動同步
  DELETE /api/cloud-accounts/:id       刪除帳號
  GET    /api/alerts                   告警列表
  PUT    /api/alerts/:id/resolve       標記已處理
  GET    /api/resources/overview       所有帳號資源概覽

用戶角色：
  ADMIN    可新增/刪除帳號、管理用戶
  OPERATOR 可操作資源，不能管理用戶
  VIEWER   只讀

阿里雲授權方式：主帳號 RAM Key + STS AssumeRole（一把 Key 管所有子帳號）
騰訊雲授權方式：各子帳號獨立 SecretId/SecretKey（透過介面逐個新增）
